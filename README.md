# קורסי הרובוטיקה של טכנודע

כל אתרי הקורסים במקום אחד, מוצגים דרך GitHub Pages.

| תיקייה | קורס | איך עורכים |
|---|---|---|
| `microbit/` | מעבדת מיקרוביט | `microbit/README.md` |
| `fll/` | FIRST LEGO League | `fll/README.md` |

- **האפיון והתוכנית:** `docs/SPEC.md`
- **הוראות ל-Claude Code:** `CLAUDE.md`

## צפייה במחשב
מריצים שרת מקומי בתיקייה הראשית: `python3 -m http.server 8000`, ואז:
- דף הבית: http://localhost:8000
- מיקרוביט: http://localhost:8000/microbit/
- FLL: http://localhost:8000/fll/
